# DNSGuard Live — نظام كشف ومنع تسريب البيانات عبر DNS

هذا النظام يحوّل بحث DNSGuard إلى نظام شغّال: يقرأ طلبات DNS الحقيقية، يفحص كل طلب بنماذج الورقة نفسها (v2 + v4 XGBoost + نموذج الحروف CNN)، يرفع تنبيهات وحوادث بشرح عربي، ويكدر **يمنع** النطاق المشبوه على خادم DNS. يجي ويّاه لوحة مراقبة عربية وأدوات مختبر لقياس الأداء.

> النظام يستخدم حزمة النماذج `dnsguard_bundle_v4.zip` اللي طلّعناها من دفتر Kaggle. ما بيه تدريب هنا — بس تشغيل النماذج الجاهزة.

---

## 1) شنو يسوي النظام

```
مصدر الطلبات ─▶ المحرّك (detector) ─▶ السياسة ─▶ تنبيه/حادثة ─▶ لوحة المراقبة
   (سجل DNS                                     │
    أو التقاط                                    └─▶ (وضع المنع) ─▶ حظر النطاق على خادم DNS
    أو إعادة تشغيل)
```

- **المحرّك:** لكل طلب يحسب 37 خاصية بشكل تدفّقي (نفس خصائص التدريب)، ويشغّل النماذج الثلاثة.
- **السياسة:** ينطلق تنبيه إذا (أي نموذج أشجار ≥ عتبته، أو CNN ≥ عتبته) **و** النطاق مو بقائمة السماح **و** أقل من ٥ أجهزة سألت عنه بالساعة الأخيرة. **الحادثة** = ٣ تنبيهات لنفس (الجهاز، النطاق) خلال ١٠ دقائق.
- **المنع:** عند فتح حادثة بوضع `block`، النظام يضيف النطاق المسجَّل لقائمة حظر خادم الـ DNS، فكل الأسماء الفرعية تنرفض ويتوقف التسريب.

---

## 2) التنصيب

يحتاج Python 3.9+ وحزمة النماذج. على حاسبة النظام:

```bash
pip install xgboost scikit-learn numpy joblib torch        # torch للـ CNN (CPU كافي)
pip install scapy                                          # فقط إذا راح تلتقطين من الشبكة مباشرة (sniff/pcap)

python3 -m dnsguard_live --bundle dnsguard_bundle_v4.zip --source demo
# افتحي http://localhost:8080/
```

`demo` يشغّل محاكاة جاهزة (جهاز طبيعي + تسريب سريع Base32 + تسريب بطيء Hex) حتى تشوفين اللوحة تشتغل بدون أي إعداد.

---

## 3) مصادر الطلبات (`--source`)

| المصدر | الاستعمال |
|---|---|
| `demo` | محاكاة داخلية للعرض والتجربة |
| `dnsmasq:/var/log/dnsmasq/queries.log` | خادم dnsmasq أو **Pi-hole** (الأشيع) |
| `bind:/var/log/named/queries.log` | خادم BIND |
| `unbound:/var/log/unbound.log` | خادم Unbound |
| `zeek:/opt/zeek/logs/current/dns.log` | مستشعر Zeek |
| `sniff:eth0` | التقاط مباشر من كارت الشبكة (يحتاج root + scapy) |
| `pcap:capture.pcap` | إعادة تشغيل ملف التقاط |
| `csv:file.csv` | إعادة تشغيل ملف بصيغة Daumel |
| `stdin` | سطر لكل طلب: `اسم [جهاز]` |

افتراضياً، مصادر السجل **تتابع** الملف مثل `tail -F`. للتحليل اللاحق لملف كامل: زيدي `--replay`.

## 4) وضع المنع

```bash
python3 -m dnsguard_live --bundle dnsguard_bundle_v4.zip \
    --source dnsmasq:/var/log/dnsmasq/queries.log \
    --mode block --block-backend dnsmasq \
    --reload-cmd "sudo systemctl reload dnsmasq" \
    --never-block uobabylon.edu.iq
```

خيارات المنع (`--block-backend`): `dnsmasq` · `pihole` · `unbound` · `rpz` (لـ BIND) · `command` (أوامرك الخاصة عبر `--block-cmd/--unblock-cmd`).

- `--dry-run` يسجّل أوامر المنع بدون تنفيذها (للتجربة الآمنة).
- `--never-block` نطاقات ما تنحظر أبداً (مثل نطاق جامعتك).
- تكدرين تبدّلين بين «مراقبة» و«منع» من اللوحة نفسها.

> **مهم:** المنع على DNS يشتغل بس إذا الأجهزة ما تكدر توصل لخوادم DNS ثانية مباشرة. بالمختبر، أجبري كل DNS يمرّ عبر المحوّل (شوف `lab/`).

## 5) اللوحة

لوحة عربية تتحدّث كل ثانيتين: عدّادات (طلبات، تنبيهات، حوادث نشطة، نطاقات محظورة)، رسم حركة الطلبات، قائمة الحوادث مع السبب وأمثلة وحجم مسرّب تقريبي، أزرار منع/إلغاء منع/السماح (إنذار كاذب)، جدول الأجهزة، آخر التنبيهات، وسجل النظام. تنزيل الحوادث CSV من زر بأعلى القائمة.

- محلياً تفتح بدون رمز. إذا شغّلتيها على `--host 0.0.0.0` (حتى تفتحينها من جهاز ثاني)، لازم `--token <رمز>`، ويصير الرابط `http://IP:8080/?token=<رمز>`.

## 6) المختبر (قياس الأداء)

مجلّد `lab/` يجهّز تجربة حقيقية بثلاث أجهزة افتراضية بشبكة معزولة. **الهجوم نفسه نسوّيه بأدوات التسريب الجاهزة والمعروفة** (iodine، dnscat2، dns2tcp، dnsexfiltrator) — نفس الأدوات اللي بيانات Daumel مبنية منها. سكربتاتنا بس تقيس وتسجّل الحقيقة، ما تولّد هجوم.

- `setup_resolver.sh` — جهاز المحوّل: dnsmasq + سجل الطلبات + توجيه زونات المختبر لجهاز المهاجم.
- `setup_attacker.sh` — جهاز المهاجم: تنصيب الأدوات + خادم الاستقبال.
- `dnslab.py sink` — خادم يرد على الطلبات ويسجّل شنو وصله (`received.csv`).
- `dnslab.py benign` — ترافيك طبيعي لقياس الإنذارات الكاذبة.
- `dnslab.py mark start/stop` — يسجّل وقت كل تشغيل لأداة حقيقية بـ `ground_truth.csv`.
- `evaluate_lab.py` — يحسب نسبة الكشف (Recall)، والإنذارات الكاذبة (FPR)، وكم بيانات وصلت للمهاجم قبل/بعد المنع.

خطوات مختصرة: شغّلي المحوّل والمهاجم والـ sink، شغّلي DNSGuard على المحوّل، سجّلي كل تشغيل أداة بـ `mark`، وبالنهاية:

```bash
python3 evaluate_lab.py --db dnsguard_events.sqlite --truth ground_truth.csv --received received.csv
```

---

## 7) حدود النسخة الحالية

- **DoH (DNS المشفّر):** هذي النسخة تقرأ طلبات DNS العادية. طلبات DoH تحتاج مصدر يفك تشفيرها (مثل سجل Pi-hole اللي يعمل كبوابة DoH) — موجود بخطة التطوير.
- المنع على مستوى النطاق المسجَّل، فنطاق مهاجم جوّا خدمة مشتركة (مثل نطاق سحابي عام) ما ينحظر حتى لا نأذي خدمة شرعية — هذي حالة نادرة بالتسريب الحقيقي.
- لازم يشتغل على جهاز داخل الشبكة يشوف الطلبات، مو على Kaggle.
